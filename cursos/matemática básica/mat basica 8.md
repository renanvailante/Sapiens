# Estação 08 — Radiciação

## Objetivo

Você vai simplificar raízes, operá-las com segurança e relacioná-las com potências de expoente fracionário.

## Pré-requisitos

Potenciação (Estação 07).

## Conteúdo

A raiz é a operação inversa da potência.

`ⁿ√a = b` significa que `bⁿ = a`

- `√9 = 3`
- `³√8 = 2`
- `⁴√16 = 2`

### Propriedades

| Propriedade | Exemplo |
|---|---|
| `√(a × b) = √a × √b` | `√(4 × 9) = 2 × 3 = 6` |
| `√(a/b) = √a / √b` | `√(16/4) = 4/2 = 2` |
| `(√a)² = a` | `(√7)² = 7` |
| `√(a²) = |a|` | `√((−3)²) = 3` |
| `ⁿ√(aᵐ) = a^(m/n)` | `³√(2⁶) = 2² = 4` |

### Simplificação de raízes

Fatore o radicando em fatores primos e retire os que aparecem com expoente igual ao índice.

`√72 = √(36 × 2) = √36 × √2 = 6√2`

### Racionalização

Eliminar a raiz do denominador, multiplicando numerador e denominador pelo conjugado ou pela raiz apropriada.

`1/√2 = √2/2`

## Exemplos resolvidos

**Exemplo 1.** Simplifique `√50`.
- `√50 = √(25 × 2) = 5√2`

**Exemplo 2.** Calcule `√2 × √8`.
- `√(2 × 8) = √16 = 4`

**Exemplo 3.** Calcule `√18 / √2`.
- `√(18/2) = √9 = 3`

**Exemplo 4.** Racionalize `3/√5`.
- `3/√5 × √5/√5 = 3√5/5`

## Estratégias

- Antes de calcular, tente fatorar o radicando por quadrados perfeitos: `4, 9, 16, 25, 36, 49, 64, 81, 100`.
- Raiz de produto se transforma em produto de raízes — use isso para simplificar.
- Em expressões com radicais, agrupe tudo sob a mesma raiz sempre que possível.
- `√a + √b ≠ √(a + b)`. Não existe propriedade para soma.

## Erros comuns

- **Somar radicais indevidamente.** `√4 + √9 = 2 + 3 = 5`, mas `√(4+9) = √13 ≈ 3,6`.
- **Esquecer o módulo.** `√(x²) = |x|`, não `x`, quando `x` pode ser negativo.
- **Cancelar raízes com termos somados.** `√(a + b) ≠ √a + √b`.
- **Deixar a raiz no denominador** quando o problema pede forma simplificada.

## Desafio final

Simplifique:

`(√12 + √27) / √3`

**Resposta:** 5

**Resolução:**
- `√12 = 2√3`
- `√27 = 3√3`
- `2√3 + 3√3 = 5√3`
- `5√3 / √3 = 5`
