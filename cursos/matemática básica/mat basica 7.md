# Estação 07 — Potenciação

## Objetivo

Você vai operar potências com segurança: aplicar as propriedades, lidar com expoentes negativos e fracionários e reconhecer os erros mais comuns.

## Pré-requisitos

Operações fundamentais (Estação 01).

## Conteúdo

Potência é uma multiplicação repetida.

`aⁿ = a × a × ... × a` (n fatores)

- `a` é a **base**
- `n` é o **expoente**

### Propriedades

| Propriedade | Exemplo |
|---|---|
| `aᵐ × aⁿ = aᵐ⁺ⁿ` | `2³ × 2² = 2⁵ = 32` |
| `aᵐ ÷ aⁿ = aᵐ⁻ⁿ` | `2⁵ ÷ 2² = 2³ = 8` |
| `(aᵐ)ⁿ = aᵐ·ⁿ` | `(2³)² = 2⁶ = 64` |
| `(a × b)ⁿ = aⁿ × bⁿ` | `(2×3)² = 4 × 9 = 36` |
| `(a/b)ⁿ = aⁿ/bⁿ` | `(2/3)² = 4/9` |
| `a⁰ = 1` (a ≠ 0) | `5⁰ = 1` |
| `a⁻ⁿ = 1/aⁿ` | `2⁻³ = 1/8` |

### Expoente fracionário

`a^(1/n) = ⁿ√a`

`8^(1/3) = ³√8 = 2`

### Sinal da base

- `(−2)² = 4` (base negativa entre parênteses)
- `−2² = −4` (o expoente só se aplica ao 2)

## Exemplos resolvidos

**Exemplo 1.** `2³ × 2⁴`
- Mesma base, soma expoentes: `2⁷ = 128`

**Exemplo 2.** `(3²)³`
- Multiplica expoentes: `3⁶ = 729`

**Exemplo 3.** `5⁻²`
- `1/5² = 1/25 = 0,04`

**Exemplo 4.** `16^(1/4)`
- `⁴√16 = 2`, pois `2⁴ = 16`

## Estratégias

- Antes de calcular, verifique se as bases são iguais. Se não, tente reescrever.
- `4 = 2²`, `8 = 2³`, `9 = 3²`, `27 = 3³` — memorize essas equivalências.
- Expoente negativo não deixa o número negativo; ele inverte a fração.
- Em expressões grandes, fatore tudo em primos e agrupe.

## Erros comuns

- **Somar expoentes em vez de multiplicar em potência de potência.** `(2³)² = 2⁶`, não `2⁵`.
- **Achar que `a⁰ = 0`.** É `1`.
- **Confundir `(−3)²` com `−3²`.** O primeiro é `9`; o segundo é `−9`.
- **Tratar expoente negativo como sinal.** `2⁻³ = 1/8`, não `−8`.

## Desafio final

Simplifique e calcule:

`(3⁴ × 3⁻²) ÷ 3⁻³`

**Resposta:** 243

**Resolução:**
- Numerador: `3⁴ × 3⁻² = 3²`
- `3² ÷ 3⁻³ = 3^(2 − (−3)) = 3⁵ = 243`
