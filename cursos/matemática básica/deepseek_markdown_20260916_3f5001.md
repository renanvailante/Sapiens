# mat basica 16 — Inequações

## Objetivo

Você vai resolver inequações do 1º grau, representar soluções em intervalos e reconhecer quando o sinal da desigualdade deve ser invertido.

## Pré-requisitos

Equações do 1º grau (Estação 11).

## Conteúdo

Uma inequação é uma desigualdade:

`ax + b > 0`, `ax + b ≥ 0`, `ax + b < 0`, `ax + b ≤ 0`

A solução é um **conjunto de valores**, não um único valor.

### Regra de ouro

Multiplicar ou dividir os dois lados por um número **negativo** **inverte o sinal** da desigualdade.

- `−2x > 6` → `x < −3`
- `−x ≤ 4` → `x ≥ −4`

Somar ou subtrair não altera o sinal.

### Representação em intervalos

| Desigualdade | Intervalo |
|---|---|
| `x > a` | `]a, +∞[` |
| `x ≥ a` | `[a, +∞[` |
| `x < a` | `]−∞, a[` |
| `x ≤ a` | `]−∞, a]` |
| `a < x ≤ b` | `]a, b]` |

Colchete virado para fora do intervalo indica que a extremidade **não** entra. Colchete virado para dentro indica que entra.

## Exemplos resolvidos

**Exemplo 1.** Resolva `x + 3 > 7`.
- `x > 4`
- Intervalo: `]4, +∞[`

**Exemplo 2.** Resolva `2x < 10`.
- `x < 5`
- Intervalo: `]−∞, 5[`

**Exemplo 3.** Resolva `−x > 3`.
- Multiplicando por −1 e invertendo: `x < −3`

**Exemplo 4.** Resolva `3x − 4 ≤ 8`.
- `3x ≤ 12`
- `x ≤ 4`

**Exemplo 5.** Resolva `3(x − 1) < 2(x + 2)`.
- `3x − 3 < 2x + 4`
- `x < 7`

## Estratégias

- Trate como uma equação, mas **fique atento ao sinal** ao multiplicar ou dividir por negativo.
- Ao passar um número negativo para o outro lado **somando ou subtraindo**, o sinal **não** muda.
- Em problemas contextualizados, verifique se a solução faz sentido (preço positivo, tempo positivo).
- Represente graficamente na reta numérica quando ajudar a visualizar.

## Erros comuns

- **Esquecer de inverter o sinal** ao multiplicar/dividir por negativo.
- **Apresentar apenas um valor** como resposta. Inequações têm infinitas soluções.
- **Confundir `]a, b[` com `[a, b]`.** Os extremos mudam o conjunto.
- **Trocar o sinal ao somar/subtrair.** Só multiplicação e divisão por negativo invertem.

## Desafio final

Resolva:

`(x − 1)/2 > (x + 1)/3`

**Resposta:** x > 5

**Resolução:**
- Multiplicando por 6: `3(x − 1) > 2(x + 1)`
- `3x − 3 > 2x + 2`
- `x > 5`
